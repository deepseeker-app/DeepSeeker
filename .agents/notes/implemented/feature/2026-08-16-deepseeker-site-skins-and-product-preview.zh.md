# Agent Note: DeepSeeker 官网皮肤页与产品预览

Status: implemented

[English](2026-08-16-deepseeker-site-skins-and-product-preview.md) | 中文

## Problem

官网一开始用了低分辨率产品截图。放大后，对话文字和测试输出反而最抢眼。后面换图时又误用了官方 Harness 界面。第一版皮肤页也只是 CSS 手绘卡片，根本看不出真实皮肤。首屏还有两个问题：三层鲸鱼直接用了 Canvas 模糊，入场动画和滚动动画又同时修改容器透明度，向下滚动再回到顶部时，首屏内容可能继续隐藏。

## Decision

所有首屏鲸鱼都关闭 Canvas 模糊。远近只靠大小、透明度、速度和描边粗细区分。首屏文案和安装框的位移、透明度由一个 ScrollTrigger 明确写入，反向滚动会把两个容器恢复到可见状态。

产品区使用 `apps/site/public/deepseeker-app.png`。这张 `1440x810` PNG 恢复了之前选中的浅色鲸吟构图，保留空白会话的标题、工作区、模式和输入框。旧图里的测试对话、个人会话列表、余额面板、右侧文件栏和桌宠都没有带进来。更紧的裁切让标题和输入框在官网卡片里显示得更大，克制的重采样只处理边缘清晰度，不改浅色水纹的整体感觉。官网没有叠加第二层窗口栏、生成式仪表盘或透视倾斜；图片地址加了新版本参数，浏览器不会继续显示刚才那张深色图。

`apps/site/skins/index.html` 是第二个 Vite 入口，地址为 `/DeepSeeker/skins/`。页面基于 Apache-2.0 的 `dsh-web-ui` Gallery 实现，保留 10 款皮肤的真实亮暗截图、三列排布、搜索分类、WebGL 背景、跟随指针的卡片倾斜和追光、模拟器弹窗、亮暗切换与复制命令。入口换成 DeepSeeker，源码、包名、作者和许可证信息都保留。

## Alternatives considered

**继续用旧图，再用 CSS 盖住文字。** 文字已经烤进位图，`1203x768` 的源图放大后仍会暴露压缩和软边。

**继续用模糊表示鲸鱼远近。** 彩色鲸鱼看起来像渲染坏了。大小、透明度、速度和描边已经能分出层次，轮廓也更舒服。

**直接跳到外部 Gallery。** 用户会离开官网，页面能不能用也要看别人的服务。现在整套浏览和预览都放在 DeepSeeker 自己的路由里。

**继续用 CSS 手绘皮肤卡片。** 这些只是模糊占位，看不出用户真正会装到什么。Apache-2.0 源码已经带了真实截图和模拟器，直接用这套才靠谱。

## Consequences

首页产品图换成了清晰的真实空白工作台，首屏向下再向上滚动也能恢复，所有鲸鱼轮廓保持清晰。官网构建产物增加第二个 HTML 入口。皮肤页现在会发布 Gallery 运行代码和 20 张高清预览图，以后更新时要一起维护清单、截图、源码标注和许可证。

## Verification

Vite 生产构建会输出两个 HTML 入口。浏览器检查覆盖首屏透明度与位移恢复、DeepSeeker 实机图的地址与尺寸、10 张皮肤卡和 20 张截图、搜索分类、卡片倾斜、WebGL 就绪、模拟器弹窗与亮暗切换、桌面和 `390x844` 布局、横向溢出和控制台错误。
