# Agent Note: DeepSeeker 内置 Web 功能套件

Status: implemented

[English](2026-08-15-deepseeker-built-in-web-suite.md) | 中文

## Problem

桌面应用需要直接带上 `dsh-web-ui` 里有用的功能，普通用户不该自己安装并组合 11 个插件。只依赖聚合包还不够：图像理解不在聚合包里，安装回退修复没有沿 pnpm 的隔离依赖链接继续扫描，还有几个已发布包需要本地兼容补丁。

## Decision

`@deepseek-ai/dsh-web-app` 把 `@linxin666/dsh-web-ui-all` 和 `@linxin666/dsh-tool-describe-image` 锁定在 `0.1.12`。浏览器名录用 11 个明确的 Loader 行装载聚合兼容层、插件设置、AionUI 文件与预览面板、任务看板、Git 图谱、桌面鲸鱼娘、远程 Web UI、实时统计、SSH、图像理解和皮肤中心。聚合包提供其余同版本的传递依赖，其中包含 9 款皮肤。

安装回退修复会先用 `realpathSync` 解析每个找到的包目录，再扫描它的 manifest。这样能沿 pnpm virtual store 的链接进入每个包隔离的 `node_modules`，并把完整插件依赖放进 profile 回退目录。

10 个 pnpm 补丁属于正式交付记录。皮肤中心会额外到 `$DSH_HOME/profiles/node_modules/@linxin666` 查找皮肤载体。Web UI 设置桥会公开图像理解的设置命名空间。任务看板把每列最小宽度设为 180 像素，五列放不下时允许横向滚动。鲸鱼娘会把保存位置、拖动位置和召回按钮限制在当前窗口内。它的状态轮询在每个标签页只允许一条请求进行；卡住的请求会超时，失败后会退避，插件卸载时会一起清理请求、定时器、设置监听和 React 根。AionUI 会从文件树和搜索中滤掉 `._*` AppleDouble 文件；宽度低于 580 CSS 像素时，文件栏和预览栏宽度会变成零，无法使用的悬浮展开按钮也会隐藏。更宽的布局保留上游可拖动面板。

浏览器 HMR 会提供一套共享 EventSource 服务。HMR、AionUI、Git 图谱和任务看板会用 Web Locks 为每条同源事件流选出一个持有者，再通过 `BroadcastChannel` 把帧转给其他标签页：`plugins` 接收 `/plugins/events` 的默认消息，`aionui-panel:${root}` 与 `git:${path}` 接收具名 `change` 事件，`task-board` 接收默认消息。事件名也属于协调 key，具名事件和默认消息不会串线。不支持这两个浏览器能力时，仍使用原来的本地 EventSource。这样既保留热更新和各功能的实时事件，也避免两个桌面标签页先把 Chromium 的 6 条 HTTP/1.1 连接全部占完，导致设置或配对请求发不出去。

SSH 补丁在首次连接时记录 SHA-256 主机密钥指纹，后续会再次核对目标主机和每一跳 ProxyJump。主机密钥变化时直接失败，不会重试。修改或删除主机配置会断开对应隧道和连接池，已经建立的会话不能继续使用旧地址。SSH 的 HTTP 与 WebSocket 路由同时要求回环 TCP 来源和回环 Host。远程 HTTP 授权器只要看到 Cloudflare 或标准代理客户端头，就不会给桌面快捷权限，即使代理通过回环连接并改写了 Host。图片补丁会先检查跨站标记与 Origin，再接受真实回环请求或远程插件给出的有效配对结果；上传或读取原图未获授权时，会在读取请求体或附件存储前返回 403。

手机访问默认关闭。Web 命令拒绝 `--host 0.0.0.0`，远程面板会引导用户打开自动公网隧道。远程插件只会在用户主动开启后才建立 Cloudflare 临时隧道。首次返回 `lan-required` 后，配对面板会保留状态流；第一条 tunnel URL 到达时自动重新签发。关闭、重开和卸载都会中止当前 run 并断开状态流。手机简版 API 只开放工作区列表、有限的会话操作和会话事件流；设置、密钥、本机操作、Goals、subagent、SSH 管理和 SSH 终端都不在这个前缀内。手机工作区首页和会话列表不会启动会话事件流；只有聊天页会启动，离开聊天页就会立即关闭。空白会话在列表和聊天页顶部都显示“新会话”，不会沿用工作区名称。共享 Web API 只会让带有效配对 Cookie 的设备调用普通方法；本机操作、配置与密钥访问、agent preset 编辑、模型发现，以及声明为仅回环的插件接口仍只能在本机调用。Web bundle 会打开 `requireRemoteAuthorization`；远程授权器尚未挂载或已经卸载时，非回环共享 API 和 WebSocket 请求直接拒绝。手机对话只显示 `source.kind` 为 `user` 的消息，运行上下文、skill 目录、AGENTS 指令和以后新增的非用户来源都不会出现在手机上。历史翻页使用原始事件序号；哪怕一整页都是被隐藏的内部消息，也能继续往前加载。每页只请求 5 条消息，因为工具密集型回合可能展开成数千个原始事件；手机 unary 请求在 15 秒后中止，隧道失联会显示错误，不会一直停在“加载中”。第三方声明按保守方式同时记录 `dsh-web-ui-all` 的 Apache-2.0 字段和发布包内的 BSD-3-Clause 许可证文件。

## Alternatives considered

**把上游源码复制进本仓库。** 不采用，因为源码分叉会让每次上游修复都变成人工合并，也会混淆外部代码的归属。锁定版本，再保留少量经过检查的补丁，差异更容易审查。

**只挂载聚合包。** 不采用，因为它没有图像理解，而且最终装载名录藏在聚合包内部。明确列出各行后，桌面功能组合可以直接测试，聚合包继续负责携带依赖。

**默认让 Web 服务器监听所有网卡。** 不采用，因为这会在用户没有明确操作时把 coding agent 暴露到局域网。临时隧道让公网暴露可见，也能随时关闭。

## Consequences

源码运行、安装后的 profile 和桌面安装包会使用同一套锁定功能。聚合包的定向测试会拦住外部行缺失或顺序变化、版本漂移、图像理解被意外删掉、主机配置变化后复用旧 SSH 连接、主机密钥变化，以及图片接口未授权访问。依赖安装和打包会带上 Cloudflare 与 SSH 运行组件，安装包会变大。SSH 回归使用本机可控的 SSH socket；真实手机通过 5G 配对、公网隧道、外部 SSH 主机、视觉模型调用和 Windows 打包仍需要对应环境下的验收。
